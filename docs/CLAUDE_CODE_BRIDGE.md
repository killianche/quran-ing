# Мост Cursor → Claude Code

> **Имя для запроса:** «передай в Claude», «мост», «пиши в Claude Code».
>
> **TL;DR.** Владелец пишет в чат Cursor (этот SSH-workspace). Мост-агент
> слегка улучшает формулировку и передаёт задачу в **Claude Code** на той же
> машине. Код и длинную работу делает Claude Code; мост показывает ход и
> отличает «я» от «он».

Сверено с решением владельца **2026-09-03**.

## Зачем так

- Владелец работает через Cursor Remote SSH (`fornex-usa` /
  `350672.fornex.cloud`), каталог `/root/projects/QuranIng`.
- Claude Code открыт в соседней панели того же workspace (сессия an-NUR /
  QuranRu) и уже держит длинный продуктовый контекст.
- Мост не подменяет Claude Code: он **маршрутизирует** задачи и **докладывает**.

## Роли

| Кто | Делает | Не делает |
|---|---|---|
| **Владелец** | Пишет задачу мосту обычным языком; говорит «1» / «передай Claude» | Не обязан сам печатать в панель Claude Code |
| **Мост (чат Cursor)** | Читает STATUS/код при необходимости; **улучшает промпт**; шлёт в сессию Claude Code; мониторит транскрипт/вывод; отвечает владельцу с пометкой «я» / «Claude Code» | **Не пишет код и не правит проект.** Не забирает реализацию себе, даже если Claude Code упёрся в permissions — тогда докладывает блокер и переотправляет / просит владельца |
| **Claude Code** | Исследует, пишет код, тесты, STATUS, коммиты — по правилам `CLAUDE.md` | Не обязан видеть диалог моста; получает самодостаточный бриф |

## Когда включать

- Владелец явно сказал: «1», «передавай Claude», «пиши в Claude Code», «мост».
- Задача продуктовая / многошаговая и логично идёт в уже живую сессию Claude Code.

## Когда НЕ включать (мост работает сам)

- Мелкий вопрос («что в STATUS?», «видишь SSH?»).
- Владелец явно сказал делать здесь / без Claude Code.
- Нужно только прочитать последний ответ Claude Code и пересказать.

## Как улучшать промпт

Мост **может** слегка улучшить текст владельца перед отправкой. Цель —
меньше холостых кругов у Claude Code, не переписать задачу.

**Добавлять:**

- абсолютный рабочий каталог `/root/projects/QuranIng`;
- цель одним абзацем;
- что уже есть в проекте (файлы, схема, экраны);
- что уже выяснил мост (факты, пути, ловушки) — чтобы не дублировать разбор;
- жёсткие правила: сакральный verbatim, граница проекта, не публиковать
  контуры без просьбы;
- критерий «если упрёшься — остановись и опиши, не выдумывай»;
- порядок шагов, если он очевиден (извлечение → данные → UI).

**Не делать:**

- менять смысл задачи владельца;
- сужать эталонный вариант ради «проще» (правило качества в `CLAUDE.md`);
- подмешивать чужие проекты или догадки как факты;
- сочинять сакральный текст «для примера» в брифе.

## Как передавать технически

Сессия Claude Code по QuranRu (пример id из 2026-09-03):

`906cfba7-3406-4651-819a-e1cda5820693`

Транскрипт:

`/root/.claude/projects/-root-projects-QuranIng/<session-id>.jsonl`

Отправка non-interactive (с сервера, из каталога проекта):

```bash
cd /root/projects/QuranIng
claude -p \
  --resume <session-id> \
  --permission-mode bypassPermissions \
  --output-format text \
  "$(cat <<'EOF'
…улучшенный бриф…
EOF
)"
```

Актуальный session id брать из живого процесса Claude Code
(`ps` / `--resume=…`) или из самого свежего jsonl в
`/root/.claude/projects/-root-projects-QuranIng/`.

## Как отвечать владельцу

В каждом сообщении моста, пока идёт мостовая работа, явно разделять:

```
### Я (мост)
…что сделал мост: передал, улучшил так-то, статус процесса…

### Claude Code
…последний ответ / ход / цитата из транскрипта…
```

Не смешивать «я сделал фичу» с работой Claude Code.

## Нюансы UI

- Сообщение через CLI попадает в **ту же историю сессии**, но в левой панели
  Cursor может не появиться сразу (панель кормит расширение stream-json).
- Источник истины для моста — транскрипт jsonl и stdout CLI, не скриншот панели.
- Пока Claude Code крутит длинную задачу, мост не перехватывает ту же фичу
  «себе», если владелец не сказал иное.
- **Запись файлов.** CLI с `--permission-mode bypassPermissions` всё равно
  может упереться в запрет записи внутри resumed IDE-сессии. Мост **не
  применяет правки сам** (решение владельца 2026-09-03). Действия моста:
  доложить блокер, переотправить в Claude Code с другим способом
  (новая сессия / без resume IDE / явный approve), либо спросить владельца.
